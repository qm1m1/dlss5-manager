# 开发计划与产品发展阶段

## 产品发展阶段
- **第一阶段**: 实现 DLSS Swapper 类功能（游戏扫描、DLSS 检测、DLL 替换、备份恢复）。
- **第二阶段**: 增加 DLSS版本库、兼容性评分、GPU分析、游戏配置管理。
- **第三阶段**: 形成 DLSS版本中心 + 游戏优化平台 + Benchmark系统。

## 开发计划 (Phases)
- **Phase 1 MVP (2-4周)**: 完成 WPF框架、游戏目录选择、DLL检测、版本读取、备份、替换、恢复。
- **Phase 2**: 增加 Steam扫描、DLSS版本库、自动下载、多版本切换。
- **Phase 3**: 增加 GPU检测、兼容数据库、游戏Profile、云端数据库。
- **Phase 4**: 增加 Benchmark、FPS分析、自动推荐、用户数据库。

## 与DLSS5-Swapper差异化
重点提升：
1. 更强的版本管理。
2. DLSS兼容性评分。
3. 性能测试闭环。
4. GPU分析。
5. 游戏配置管理。
6. 云端数据支持。

## 第一版不包含内容 (Out of Scope)
暂不开发：DLSS逆向、DirectX Hook、DLSS算法实现、AI模型、DLSS破解。
**核心准则：重点保持稳定、安全、工程化。**
